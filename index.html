1Via 地址打开设置，手动打开 ADB

在哪操作：设备 Via 浏览器 + 电脑
  1. 电脑上起设置跳转页服务： 
    python3 adb_page/lava_server.py   # 端口 8000（Windows 用 python）
  2. 设备打开 Via 浏览器，地址栏输入电脑局域网地址（如 192.168.31.36:8000），点 「③ 直达主设置界面」（开发者选项直达按钮在本机无效，勿用）。
  3. 在设置里进入开发者选项，手动打开 USB 调试（没有开发者选项就先去「关于设备」连点「版本号」7 次）。
  4. 电脑上确认连接并打开网络 ADB： 
    adb devices          # 首次弹授权框勾选「始终允许」
./setup.sh device    # 自动开 5555 → 读设备 IP → 切 WiFi ADB
设备重启后 5555 会关闭（固件限制、无 root 不能自启），插一次 USB 重跑 ./setup.sh device 即可。装好壳后日常使用不再依赖 ADB。

2Via 生成应用台（含全部优化）

在哪操作：电脑起服务，设备 Via 打开
  1. 电脑上起应用台服务： 
    ./setup.sh serve -d   # 后台常驻，打印 http://<电脑IP>:8900/
    首次启动自动建虚拟环境、装依赖、生成 10 张内置壁纸。
  2. 设备 Via 打开打印出的地址（建议设为 Via 主页）。装壳后桌面图标是主入口，Via 作备用通道。
  3. USB 调试自动恢复（一次性授权，装完第 3 步的壳后生效）： 
    adb shell pm grant com.apple.android.music android.permission.WRITE_SECURE_SETTINGS
    每次打开应用台，壳自动把被关掉的 USB 调试开关拉回来（./setup.sh shell 会自动执行此授权）。
  • 壁纸：必应每日 / 10 张内置 / 手机扫码上传，网格切换、可删上传
  • 我的最爱居中置顶，长按图标快速加/删；「全部应用」「系统设置」折叠展开
  • 强杀应用：两段确认强制结束进程，运行中应用红框高亮
  • 屏保：5/10/20/30 分钟、1 小时可选；遮罩三档；四款时钟（翻页 / 极简数字 / 表盘 / 中文文字钟），24 小时制
  • 启动三级兜底（壳桥 → ADB → 系统 intent）；RK3399 级性能优化；页面 30 秒自动更新

3用系统自带 Apple Music 换壳成应用台

在哪操作：电脑一条命令
./setup.sh shell --pkg com.apple.android.music

脚本自动完成：备份原 APK → 写入服务地址 → 构建 → 签名 → 安装 → 授予 WRITE_SECURE_SETTINGS。 完成后点桌面「Apple Music」图标就是应用台（壳模式 · 免 ADB，断电重启可用）。

  • 非交互：./setup.sh shell --pkg com.apple.android.music --ip 192.168.31.36
  • 顶替其他系统应用：把 --pkg 换成设备上已存在的包名
  • 还原原版：adb install -r backup/com.apple.android.music-<时间>.apk
  • 注意：部分定制桌面按包名硬编码图标名，改壳显示名不会生效（不影响使用）

4用白名单槽位方式安装其他软件

在哪操作：电脑一条命令一个 APK

LAVA 桌面会强杀「固件不认识」的应用（启动约 0.1 秒被杀）。唯一可靠的办法：把 APK 改包名成固件白名单里的包名（槽位）再安装：

./install_app.sh 某个应用.apk                    # 自动挑空槽位
./install_app.sh 某个应用.apk --pkg <槽位>       # 指定槽位
./install_app.sh 某个应用.apk --yes              # 免确认
  • 自动流程：读包名 → apktool 解包 → 补全相对类名 → 全局替换包名 → 重打包 → 签名 → 安装 → 5 秒启动验证
  • 槽位规则：一个槽位 = 一个固件认识且未装的包名（如 com.lavamusic.me.rank）；不要用自造包名，必被杀
  • 槽位用完就卸一个不用的应用腾出包名；加壳 APK（dex2c / 360 / 乐固等）重签后必崩，不能用此流程
  • 普通设备（无白名单固件）直接 adb install -r xx.apk

5安装的软件自动添加到应用台

在哪操作：无需操作，自动完成

?常见问题

应用台打开白屏 / 转圈

电脑服务没起（lsof -i:8900 或任务管理器查 python），或电脑 IP 变了（路由器 DHCP 固定电脑 IP；或重跑 ./setup.sh shell --ip 新IP）。

设备重启后 5555 连不上

固件级限制：USB 调试开关打开应用台会自动恢复（需已授权），但 5555 端口必须插 USB 跑一次 ./setup.sh device。

覆盖安装失败（签名不一致）

adb uninstall <包名> 后重装；原应用可从 backup/ 装回。

电脑重启后

手动跑一次 ./setup.sh serve -d（Windows 在 Git Bash 里跑）。
